# SnehBandhu Clinic Website

React + Vite + Tailwind CSS website built from the **information/data contained in the supplied reference images**.

## Important
The supplied reference images are **not displayed on the website**. Their text, contact details, brand colors, typography direction, service descriptions, plans, and leadership principles were converted into native website content and UI components.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Brand direction
- Deep Emerald: `#006B52`
- Champagne Gold: `#D4B06A`
- Royal Navy: `#102A5C`
- Premium serif headlines inspired by the supplied brand guide.

## Note
The callback form is front-end only and currently shows a browser confirmation. Connect it to the clinic's preferred backend/email service before production use.
